# 📂 Manifests Artifacts (Legacy)

**Эта директория является историческим артефактом проекта.** Здесь собраны декларативные манифесты, которые использовались на ранних этапах разработки для **ручного и поштучного развертывания подов** в Kubernetes напрямую через утилиту `kubectl`.

Данные конфигурации применялись до того, как управление инфраструктурой было полностью переведено на автоматизированные **Helm-чарты**.

---

## 📋 Обзор манифестов по категориям

### 🚀 Конфигурация бэкенда (Application Layer)
* **`backend.yaml`** — Базовый манифест развертывания (Deployment) основного приложения и его сетевого сервиса (Service).
* **`backend-hpa.yaml`** — Настройки горизонтального авто масштабирования подов (Horizontal Pod Autoscaler) в зависимости от нагрузки.
* **`backend-monitor.yaml`** — Кастомный ресурс (ServiceMonitor / PodMonitor) для интеграции бэкенда с системой сбора метрик.

### 📊 Мониторинг и логирование (Стек PLG / Prometheus)
* **`monitoring/`** — Подпапка с базовыми ресурсами окружения мониторинга.
* **`kube-prometheus-values.yaml`** — Конфигурация для сбора и визуализации метрик кластера.
* **`loki-values.yaml`** — Настройки хранилища логов Grafana Loki.
* **`promtail-values.yaml`** — Конфигурация агента Promtail для сборки и отправки логов из контейнеров.

### 🗄️ Базы данных и хранилища
* **`postgres.yaml`** — Манифесты для изолированного развертывания и инициализации СУБД PostgreSQL.

### 🔐 Конфигурация, секреты и сеть
* **`configmap.yaml`** — Переменные окружения и глобальные несекретные настройки приложения.
* **`secret.yaml`** — Конфиденциальные данные и доступы, необходимые для работы бэкенда.
* **`dockerhub-secret.yaml`** — Секрет (`imagePullSecrets`) для авторизации и скачивания образов из приватного репозитория Docker Hub.
* **`ingress.yaml`** — Правила маршрутизации внешнего трафика (Ingress-контроллер) к внутренним сервисам.
* **`cluster-issuer.yaml`** — Настройка Cert-Manager для автоматического выпуска и продления SSL-сертификатов.

### 🛡️ Ограничения и квоты (Resource Management)
* **`limitrange.yaml`** — Ограничения по умолчанию (Requests / Limits) на CPU и Memory для контейнеров в рамках Namespace.
* **`resourcequota.yaml`** — Жесткие лимиты на суммарное потребление вычислительных ресурсов всем окружением.

---

## ⚠️ Важное примечание

Файлы в этом каталоге **не предназначены для актуального развертывания** в Production-среде. Они сохранены исключительно для:
1. Ознакомления с историей развития архитектуры проекта.
2. Сверки старых параметров конфигурации.
3. Локальной отладки или изоляции отдельных компонентов (через `kubectl apply -f`).

> 💡 **Для актуального деплоя** используйте официальные Helm-чарты проекта из соответствующей директории /helm.
